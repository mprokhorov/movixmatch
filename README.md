# MovixMatch 🎬💞

Tinder для уже сложившихся пар — помогает выбрать фильм на вечер. Оба свайпают одни и те же карточки: вправо — «хочу», влево — «нет». Когда фильм понравился обоим — **мэтч**, и по нему открывается отдельный чат, где можно договориться, когда смотреть.

PWA: работает во вкладке браузера, а на телефоне ставится на главный экран как приложение.

## Как это работает

1. Владелец (мастер-аккаунт) вводит имя → создаётся пара и ссылка-приглашение.
2. Ссылку отправляешь партнёру → он(а) вводит своё имя → вы в паре.
3. Свайпаете. Мэтчи прилетают обоим в реальном времени, с конфетти.
4. Вкладка «Мэтчи» → чат по каждому фильму, быстрые ответы, отметка «посмотрели».

### Почему мэтчи появляются быстро
- Колода перемешана **одинаково для обоих** (seed = id пары), так что вы видите одни и те же фильмы примерно в одном порядке.
- Каждая третья карточка — фильм, который партнёр **уже лайкнул**, а ты ещё не видел(а). При обычной доле лайков ~40–50% первые мэтчи появляются уже в первые 10–20 свайпов.

## База фильмов
`public/movies.json` — 121 фильм: русские названия, оригинальные названия, год, жанры, хронометраж, короткое описание. Постеры лежат локально в `public/posters/` (500 px, ~65 КБ), service worker кэширует их для офлайна.

Исходник базы — `data/movies.tsv`, список IMDb ID — `scripts/ids.txt`.

## Деплой

Firebase Hosting + Firestore, адрес **https://movixmatch.web.app**. Пошагово — в [DEPLOY.md](DEPLOY.md).

## Устройство
- Статический фронтенд без сборки: `public/index.html`, `app.js` (ванильный JS), `styles.css`.
- Данные и синхронизация — **Firestore** (подписки в реальном времени), вход — **анонимный Firebase Auth**.
- `firestore.rules` — доступ к паре есть только у двух её участников. Место в паре можно занять (или перезанять с нового устройства) только зная секрет из ссылки: код приглашения у партнёра, личный ключ у владельца.
- `public/sw.js` — service worker (оболочка офлайн, постеры cache-first).

Структура в Firestore:
```
rooms/{roomId}                       ownerUid, partnerUid, имена
  invites/{code}                     ссылка-приглашение
  keys/{key}                         ключ входа владельца
  members/{owner|partner}            лайки, прочитанные сообщения, онлайн
  matches/{movieId}                  мэтч: «посмотрели», последнее сообщение
    messages/{id}                    чат по фильму
```

## Идеи на потом
- Динамически расширяемый пул: после мэтчей подгружать похожие фильмы (TMDB API: жанры/рекомендации к мэтчам).
- Фильтры по жанрам и настроению вечера («что-то лёгкое», «на два часа максимум»).
- Push-уведомления о мэтчах и сообщениях (Web Push + VAPID).
- «Суперлайк» и случайный выбор среди мэтчей («крутим барабан»).

Постеры — собственность правообладателей, используются для личного некоммерческого проекта.
