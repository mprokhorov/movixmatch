# MovixMatch 🎬💞

Tinder для уже сложившихся пар — помогает выбрать фильм на вечер. Оба свайпают одни и те же карточки: вправо — «хочу», влево — «нет». Когда фильм понравился обоим — **мэтч**, и по нему открывается отдельный чат, где можно договориться, когда смотреть.

PWA: работает во вкладке браузера, а на телефоне ставится на главный экран как приложение.

## Как это работает

1. Открываешь сайт → короткая анкета: имя и любимые жанры. Анкета хранится в этом браузере (анонимный вход Firebase), без регистрации.
2. В разделе «Вдвоём» создаёшь одноразовую ссылку-приглашение (действует 7 дней) и отправляешь своей половинке. Она заполняет свою анкету и принимает приглашение — вы связаны. Повторно по той же ссылке никто не войдёт.
3. Каждый свайпает свою колоду — только из любимых жанров. Лайки общие для всех связей.
4. Фильм, который лайкнули оба, — **мэтч**: прилетает обоим в реальном времени, по нему открывается чат.

Колода одна и та же для всех (известные фильмы первыми, внутри уровней популярности — общий перемешанный порядок), отфильтрованная по жанрам. Поэтому связанные люди встречают одни и те же фильмы примерно в одно время, но мэтчи случаются только там, где пересекаются вкусы.

## База фильмов
`public/movies.json` — 121 фильм: русские названия, оригинальные названия, год, жанры, хронометраж, короткое описание. Постеры лежат локально в `public/posters/` (500 px, ~65 КБ), service worker кэширует их для офлайна.

Исходник базы — `data/movies.tsv`, список IMDb ID — `scripts/ids.txt`.

## Деплой

Firebase Hosting + Firestore, адрес **https://movixmatch.web.app**. Пошагово — в [DEPLOY.md](DEPLOY.md).

## Устройство
- Статический фронтенд без сборки: `public/index.html`, `app.js` (ванильный JS), `styles.css`. Навигация внутри приложения не меняет URL.
- Данные и синхронизация — **Firestore** (подписки в реальном времени), вход — **анонимный Firebase Auth**.
- `firestore.rules`: профиль читают только сам человек и те, с кем он связан; связь создаётся только по живому одноразовому приглашению, которое удаляется в той же записи.
- `public/sw.js` — service worker (оболочка офлайн, постеры cache-first).

```
users/{uid}                    имя, жанры, лайки, онлайн
invites/{code}                 одноразовая ссылка-приглашение
pairs/{uidA_uidB}              связь двух людей, прочитанные сообщения
  matches/{movieId}            мэтч: «посмотрели», последнее сообщение
    messages/{id}              чат по фильму
```

## Обновление базы фильмов
`scripts/build-movies.mjs` собирает `public/movies.json` и постеры из TMDB:

```bash
TMDB_KEY=... node scripts/build-movies.mjs
```

## Идеи на потом
- Фильтры по настроению вечера («что-то лёгкое», «на два часа максимум»).
- Push-уведомления о мэтчах и сообщениях (Web Push + VAPID).
- «Суперлайк» и случайный выбор среди мэтчей («крутим барабан»).

Постеры — собственность правообладателей, используются для личного некоммерческого проекта.
